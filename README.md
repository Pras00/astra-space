# 🚀 ASTRA — Beyond Earth. Explore What's Next.

ASTRA is a cinematic, interactive space exploration web application engineering humanity's journey beyond Earth. Built with **Next.js 16 (App Router)**, **TypeScript**, **Tailwind CSS v4**, **Three.js / WebGL**, and **Framer Motion**.

---

## ✨ Features

- **Cinematic 3D Hero Experience**: Interactive 3D Earth globe with Rayleigh atmospheric scattering, dynamic orbiting satellite, distant lunar body, and mouse parallax.
- **Procedural Planetary Explorer**: Interactive 3D celestial bodies (Earth, Moon, Mars, Europa, Titan) with procedural surface noise textures, 360° inertia drag control, and clickable surface outpost beacons.
- **Flight Trajectory Roadmap**: Interactive aerospace milestone timeline detailing cislunar logistics, Mars expedition architectures, and deep-space missions.
- **Spacecraft Fleet Showcase**: 3D zero-g attitude viewer for ASTRA I, ASTRA II, and ASTRA III probe carriers.
- **Technology Blueprint Explorer**: Interactive wireframe blueprint with interactive subsystem telemetry hotspots (Ion Drives, Thermal Shields, Laser DSOC Comms).
- **Live Mission Control Telemetry**: Real-time trajectory tracking for Horizon Surveyor VII with streaming velocity and downlinked telemetry status.
- **Cadet Enrollment & Launch Command Modals**: Stacking-context safe application modals for aerospace personnel.
- **Deep-Space Audio Synthesis**: Ambient cosmic drone synthesizer using Web Audio API (55Hz / 82.4Hz).
- **Graceful WebGL Fallback & Accessibility**: Context-loss recovery, high-fidelity SVG/Canvas fallbacks, and full `prefers-reduced-motion` compliance.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Pras00/astra.git
cd astra
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 4. Build for production
```bash
npm run build
npm run start
```
